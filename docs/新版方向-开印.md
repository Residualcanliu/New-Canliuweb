# 新版方向 ／ 开印 · THE PRINT RUN

推翻黑底白蝴蝶那套，改用「纸上印刷」的语言。以下是拆解、概念、规范。

---

## 一、从参考项目里真正可以拿走的东西

参考项目最值得学的不是"好看"，是它把**手绘感做成了函数**。它有一个 50 行的 `sketch.ts`，里面五个东西撑起了全部画面：

| 函数 | 做法 | 效果 |
|---|---|---|
| `ring` | 半径叠两层正弦（低频抖动），收笔时**越过起点**一小段 | 圆环不是规整的，像有人一口气画完 |
| `rule` | 中段微微拱起，两端各**冲出**端点 10px | 标线不像 CAD，像用尺子压着手绘 |
| `brush` | 沿路径算法线，两端收成尖的闭合轮廓 | 笔触有粗细变化 |
| `inked` | 同一条线**偏移再描一遍**，第二遍透明度 0.26 | 这就是"套印不准"，是整套视觉的灵魂 |
| `seed rng` | 所有随机由种子驱动 | 每次刷新画面完全一致，可写测试 |

还有两条规则，比函数更重要：

1. **线宽跟着景深走**。远景（半调、大圆、放射线）线宽 ×0.6，中景 ×0.85，近景（图标、笔刷）线宽 ×1.55。所以画面有纵深，不是一层贴纸。
2. **一个页面一个印版色**。首页钴蓝、关于页朱红。同一套版式，换一块印版就是另一个页面。

## 二、为什么蝴蝶要放弃

不是因为它丑，是因为它跟这套语言不是一套东西：

- 蝴蝶是**正片**逻辑——黑底上一只白物，靠反差发亮。印刷是**负片**逻辑——白纸、黑墨、油墨叠印。两者混在一起会互相打架。
- 蝴蝶是"一个物体在动"，印刷是"一套系统在就位"。个人网站真正要证明的是后者：秩序、精度、工程能力。
- 而且蝴蝶那个开场，讲完就没了，跟页面的网格没有任何关系。印刷的开场**用的就是版式的线**——开场结束，那些线还在，变成了版心。

## 三、新开场：一张纸被印出来

| 时间 | 发生什么 |
|---|---|
| 0.00 | 只有纸、四角裁切标记、一个手绘圆环、一枚套准十字。什么都没有 |
| 0.40 | **钴蓝版落下**：整块圆盘先偏 6px，0.15s 内吸附归位；错位的那层残影留在原地不擦掉 |
| 1.10 | **网点**从圆心往外长出来，形成一圈半调环 |
| 1.60 | **黑版落下**：名字先与蓝版错开 3px，再套准。错位期间能看见蓝边 |
| 2.20 | 之前那些"辅助线"其实一直是版式线，此刻标签与横线一起定住 |
| 3.00 | **收笔**：套准十字闪一下消失，整页下压 1px，像纸被压平 |

3 秒，全程没有一个物体在飞。所有运动都是"落版—错位—套准"，这个节奏本身就是这个风格的语法。

## 四、规范（可直接执行）

**色彩**
- 纸 `#F2F1EC`　墨 `#101010`　次级文字 `#4A4A46`　辅助 `#6B6B66`
- 钴蓝 `#2B4BD8`（序章）／ 朱红 `#C6303C`（关于）／ 墨黑（作品）／ 暖灰（联络）

**字体**
- 超大标题：Noto Serif SC（衬线，允许 166px 以上的反差）
- 正文：Noto Sans SC 13/1.6
- 标签：JetBrains Mono 8–10px，全大写，用 `／` 分隔，不用斜杠 `/`

**线条**
- 主规则线 1px / 22% ；辅助线 1px / 12% ；刻度线 4px / 28%
- 所有"手绘"元素必须走 `sketch` 引擎，不许用规整的 `circle` / `line`
- 套印错位：主元素的副本偏移 2–4px，透明度 0.26–0.4

**版式**
- 版心 1376×812，四边留 64；页眉 92 / 页脚 812 两条规则线
- 左栏文字 64→560，右栏图形 600→1376
- 左下角永远放"印务说明"三行（印版、版心、版本），这是这个风格的签名

## 五、和旧版的差异

| | 旧版（蝴蝶） | 新版（开印） |
|---|---|---|
| 底色 | 纯黑 | 纸白 |
| 开场 | 一只生物飞进来，把画面撑开 | 一张纸被印出来，版式自己就位 |
| 情绪 | 神秘、剧场感 | 冷静、精密、有手工痕迹 |
| 图形 | 位图剪影 | 全部矢量手绘，可无限缩放 |
| 页面之间的关系 | 同一张黑底 | 同一套版式，换印版色 |
| 实现 | Canvas 2D + 位图 | SVG 手绘引擎 + CSS，几乎零位图 |

## 六、待你确认

1. 纸白 + 钴蓝这个方向，和你想给人的"个人气质"合不合？（旧版是神秘感，新版是专业感）
2. 名字用 `GCH` 三个字母撑一根 166px 的衬线，还是像参考那样拆两行（`G` / `C H`）？
3. 每个栏目换印版色（首页钴蓝、关于朱红、作品墨黑），还是全站只用一个钴蓝？
4. 开场 3 秒会不会太长？可以压到 1.8 秒（去掉网点那一拍）。
